# android_vendor_xiaomi_dada

Vendor blobs for Xiaomi 15 (`dada`) from HyperOS 4 CN **OS4.0.0.22.XOCCNXM**.

Requires **git-lfs**. Radio images live in `android_vendor_xiaomi_dada-firmware`.

```bash
git lfs install
git clone -b lineage-23.2 https://github.com/devine-machinery/android_vendor_xiaomi_dada.git
```
